# 可靠性、测试、评测与验收

## 超时与熔断

初始默认值：指标查询 10 秒、日志查询 15 秒、Trace 搜索 15 秒、Trace 明细 10 秒；Subagent 30 秒，Run 120 秒。每次尝试使用 min(工具超时, 子剩余时间, 父剩余时间)，退避也消耗截止时间。

MCP 瞬态失败最多追加两次尝试，指数退避加 jitter，遵守有界 Retry-After。鉴权/权限、非法参数、取消不重试。模型网络失败默认最多追加一次，归 Model 调用策略管理；参数纠错归 Harness 管理，计数分别保存且共享预算。

熔断按 MCP 实例/来源共享 closed、open、half-open 状态。仅连接/服务类故障计入熔断，模型输出非法 JSON 不应熔断健康 MCP。阈值、窗口、冷却时间配置化，测试用注入时钟；半开限制探测并发，成功恢复，失败重开。

启动时 MCP 离线允许应用降级启动、展示健康信息和后台重连。开始巡检前，必需能力缺失则拒绝该类完整巡检或显式进入已定义的部分模式。运行中丢失来源按下表收敛。

| 缺失 | 结果 |
|---|---|
| 指标 | 无法确定是否越阈值，inconclusive，可保留日志发现 |
| 日志或 Trace | partial，列出缺口并降低诊断确定性 |
| 全部来源 | inconclusive，明确数据源不可用 |
| 本地持久化不可用 | 停止继续取证，报告运行失败，不能假装可恢复 |
| LangSmith 不可用 | 本地继续，记录观测上报失败 |

降级只减少取证和结论强度，不放宽权限、不填造证据。预算耗尽后允许在剩余输出预算内给部分报告，否则返回确定性的失败/部分结果封装。

## 测试层级

单元测试覆盖四道闸门、歧义 JSON、空对象、Schema 默认值、语义收缩、权限拒绝、纠错链计数、Abort、超时与熔断。模型使用脚本化适配器，使非法参数 → LLM 纠错 → 成功/失败路径可重复。

契约测试覆盖 MCP 工具发现、Schema 漂移、ToolResponse 流、Subagent 返回、事件兼容和证据查询。安全测试验证不注册写工具、确认绑定参数、写动作幂等和 uncertain 状态。

集成测试覆盖 Compose 摄取查询、三个 Subagent 并行隔离、所有触发入口、SSE 重连、Checkpoint 重启、父子预算、成功分支不重放、压缩后引用完整。

LangSmith 评测覆盖正常场景、黄金故障、少样本、窗口不匹配、来源离线、错误 JSON、重试耗尽和无证据报告。fixture 答案对 Agent 隔离。

## V1 验收目标

- 固定 fixture 的样本、失败率及阈值判断使用确定性断言。
- 健康依赖下目标 60 秒内完成；来源故障时 120 秒硬截止内收敛。
- 单 Run 最多 20 次模型提出的工具调用，父子调用合并计数；网络尝试另有严格受限账本。
- 黄金场景 10 次实际模型运行，至少 9 次满足结构化诊断标准，并记录模型和配置版本。
- 输出引用 100% 可回查；无证据断言根因和真实写操作均为 0。
- 正常、partial、inconclusive、cancelled、failed 均有测试，不仅检查自然语言是否“看起来正确”。

这些是验收目标，不是当前已测结果。真实业务接入及生产上线需单独完成凭证管理、认证授权、负载、备份恢复、留存、部署运维和动作审查。
